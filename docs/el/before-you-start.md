# Πριν ξεκινήσετε {#before-you-start}

Δεν έχετε ξαναδουλέψει με τη γραμμή εντολών; Αυτή η σελίδα σας πηγαίνει από το μηδέν σε έναν λειτουργικό
3DHeat Watcher σε περίπου δέκα λεπτά. Πληκτρολογείτε εντολές σε ένα *τερματικό*, ένα παράθυρο όπου γράφετε μια γραμμή
και πατάτε Enter.

## 1. Εγκαταστήστε την Python {#install-python}

1. Κατεβάστε την Python 3.10 ή νεότερη από το <https://www.python.org/downloads/>.
2. Τρέξτε το πρόγραμμα εγκατάστασης. Στην πρώτη οθόνη επιλέξτε **Add python.exe to PATH**,
   και μετά κάντε κλικ στο **Install Now**.
3. Ελέγξτε την: ανοίξτε ένα τερματικό (βήμα 3) και πληκτρολογήστε `python --version`. Θα δείτε
   `Python 3.` και έναν αριθμό 10 ή μεγαλύτερο.

Στο Linux ή στο macOS, η Python συνήθως είναι ήδη εγκατεστημένη: χρησιμοποιήστε `python3` όπου αυτές οι σελίδες γράφουν `python`.

## 2. Αποκτήστε το 3DHeat Watcher {#get-3dheat-watcher}

Κατεβάστε το zip από τη [σελίδα Releases](https://github.com/Holdi601/3DHeat-Watcher/releases) και αποσυμπιέστε το,
για παράδειγμα στο `C:\Tools\3DHeat-Watcher`. (Αν έχετε Git, το `git clone` δουλεύει επίσης.)

## 3. Ανοίξτε ένα τερματικό σε αυτόν τον φάκελο {#open-a-terminal-in-that-folder}

- **Windows:** ανοίξτε τον φάκελο στην Εξερεύνηση αρχείων, κάντε κλικ στη γραμμή διεύθυνσης, πληκτρολογήστε
  `powershell` και πατήστε Enter. Ανοίγει ένα μπλε ή μαύρο παράθυρο, ήδη σε αυτόν τον φάκελο.
- **macOS / Linux:** ανοίξτε το *Terminal* και πληκτρολογήστε `cd ` (με κενό), σύρετε τον φάκελο μέσα στο
  παράθυρο και πατήστε Enter.

Το `cd <folder>` μετακινεί το τερματικό σε άλλον φάκελο. Όλες οι εντολές αυτών των σελίδων πληκτρολογούνται
μέσα στον φάκελο του ίδιου του εργαλείου.

## 4. Εγκαταστήστε όσα χρειάζεται {#install-what-it-needs}

```bash
python -m pip install -r requirements.txt
```

Στο τέλος θα δείτε `Successfully installed ...` (ή `Requirement
already satisfied`).

## 5. Ελέγξτε ότι δουλεύει {#check-it-works}

```bash
python -m heat3d_watch --version
```

Θα δείτε: `1.0.2` (ο αριθμός έκδοσης).

## Πώς να διαβάζετε τις εντολές αυτών των σελίδων {#how-to-read-the-commands-on-these-pages}

- Οι λέξεις μέσα σε `<γωνιώδεις αγκύλες>` είναι σημεία κράτησης θέσης: πληκτρολογήστε αντί γι' αυτές το δικό σας αρχείο ή φάκελο,
  χωρίς τις αγκύλες. Το `python -m heat3d_watch sessions --game <name>` σημαίνει ότι αντικαθιστάτε
  το μέρος μέσα στις αγκύλες.
- Μια διαδρομή με κενά μπαίνει σε εισαγωγικά: `"C:\My Games\my file"`.
- Οι γραμμές που αρχίζουν με `#` στα παραδείγματα είναι σχόλια· δεν τις πληκτρολογείτε.
- Η επιτυχία μοιάζει έτσι: μετά το `python -m heat3d_watch games`, ένας πίνακας με μία γραμμή για κάθε παιχνίδι.

## Συνηθισμένα σφάλματα {#common-errors}

| Βλέπετε | Τι να κάνετε |
|---|---|
| `'python' is not recognized` ή `command not found` | Η Python δεν είναι στο PATH: τρέξτε ξανά το πρόγραμμα εγκατάστασης και επιλέξτε **Add python.exe to PATH**, και μετά ανοίξτε νέο τερματικό. Στο macOS/Linux δοκιμάστε `python3`. |
| `No module named ...` | Παραλείφθηκε το βήμα 4, ή έτρεξε σε άλλον φάκελο: κάντε `cd` στον φάκελο του εργαλείου και τρέξτε το ξανά. |
| `pip is not recognized` | χρησιμοποιήστε `python -m pip ...` αντί για `pip ...`. |
| `No such file or directory` / `can't open file` | το τερματικό είναι σε λάθος φάκελο, ή η διαδρομή είναι λάθος γραμμένη: ελέγξτε την, και βάλτε τις διαδρομές με κενά σε εισαγωγικά. |
| κόκκινο κείμενο που τελειώνει σε γραμμή `error:` | διαβάστε την τελευταία γραμμή: λέει τι λείπει. Η σελίδα [Εντολές](../commands.md) απαριθμεί τα μηνύματα. |
