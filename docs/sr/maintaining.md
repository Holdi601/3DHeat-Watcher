# Одржавање ових страница {#maintaining-these-pages}

Списак за сваку верзију. Странице морају да кажу шта код заиста ради, да се читају лако за почетника, осмогодишњака и стручњака, и да постоје на сваком језику који 3DHeat приказивач подржава.

## Списак за објављивање верзије {#release-checklist}

1. **Поново генеришите генерисане странице** из кода:

   ```bash
   python tools/gen_game_pages.py
   python tools/gen_docs_reference.py
   for f in tools/diagrams/*.json; do python tools/flow2svg.py $f docs/assets/img/$(basename $f .json).svg; done
   ```

   Пре commit-а, исто то са `--check` мора да заврши са 0:

   ```bash
   python tools/gen_game_pages.py --check
   python tools/gen_docs_reference.py --check
   ```

2. **Упоредите функције од последњег објављивања.** `VERSION` садржи верзију; њена ознака је `v<VERSION>`:

   ```bash
   git log --oneline v$(cat VERSION)..HEAD
   ```

   Свака нова наредба, опција, колона, излаз или понашање добија ред на страници која га покрива, и ред у `CHANGELOG.md` под **Docs** са називом те странице.

3. **Независни преглед.** Неко ко није написао измену чита измењене странице - дијаграме и слике укључено - три пута: као почетник (никад није користио терминал), као осмогодишњак (да ли први пасус каже шта је то и зашто, једноставним речима?) и као стручњак (да ли су заставице, подразумеване вредности и колоне тачно оно што код ради?).

4. **Поправите што је преглед нашао.** Слике остају око 900 px широке, са текстом од најмање 12 px како је приказано; дијаграми се генеришу из `tools/diagrams/*.json` помоћу `tools/flow2svg.py`. Примери користе само измишљена имена (`de_x`, "Demo Valley", `<map>`): никад прави мапа, играч, ид меча или фигура из правих датотека.

5. **Преводи.** Свака преведена страница бележи хеш енглеског извора из кога је направљена. Поново преведите странице чији се хеш енглеског извора променио, па нека сваки језик прегледају на исте три начина (једноставно, за почетника, за стручњака), укључујући ознаке на дијаграмима.

6. **Слање тек уз одобрење власника.** Commit-ујте локално; власник одлучује кад то иде јавно.

## Преводи: команде {#translations-the-commands}

Сајт је преведен на 40 језика које подржава 3DHeat приказивач: енглески је у `docs/`, сваки други језик у `docs/<lang>/` са истим називима датотека. `tools/docs_i18n.py` води евиденцију:

```bash
python tools/docs_i18n.py hashes             # после сваке енглеске измене: забележи хеш сваке странице
python tools/docs_i18n.py svg-strings        # после сваке измене слике: ознаке за превод
python tools/docs_i18n.py status             # по језику: тачне, застареле, недостајуће странице
python tools/docs_i18n.py todo --lang de     # немачке странице за (поновни) превод
python tools/docs_i18n.py svg-build --lang de    # немачке слике из docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # означи немачке странице хешем енглеског извора
python tools/docs_i18n.py check              # излаз 1 кад су хешеви или ознаке застарели
```

Преводите само оно што `todo` наводи: задржите Markdown, везе, код, називе датотека и колона онакве какве јесу, преведите наслове и опис слика, и користите властите речи приказивача 3DHeat за његова дугмад и панеле (његов `src/i18n/locales/<lang>/`). Генерисане референтне странице и терминалне слике остају на енглеском. На сајту, застарео превод то каже и води на енглеску страницу; недостајућа страница се враћа на енглески. Језички мени у заглављу и преусмеравање на страницу по језику прегледача на почетној страници долазе из `docs/_includes/`.
